# 第 5 章：常用控件与表单

> 前置知识：窗口对象、方法、基本信号连接。目标：按数据类型选择控件，正确读取值，提供有用的输入校验，并完成一个可用表单。

本章完整示例是 [第二课_注册表单.py](示例代码/第二课_注册表单.py)。它叫“学习登记表”，只检查本地输入，不创建真实账户，不向网络发送数据。窗口中有昵称、练习密码、年龄、学习基础、学习目标和说明复选框。

从项目根目录运行：

```powershell
.\docs\Book\.venv\Scripts\python.exe .\docs\Book\示例代码\第二课_注册表单.py
```

先尝试空昵称、只填空格、短密码、重置，再阅读代码。你会发现，表单质量主要来自输入约束和状态处理，而不仅是控件摆放。

## 5.1 先看数据类型，再选控件

| 你要表达的数据 | 优先考虑 | 理由 |
| --- | --- | --- |
| 一行名称、路径、关键词 | `QLineEdit` | 支持单行编辑、占位提示与校验器 |
| 整数或小数 | `QSpinBox` / `QDoubleSpinBox` | 能直接约束范围，读值就是数字 |
| 从有限选项中选一个 | `QComboBox` | 节约空间，便于提供稳定选项 |
| 是否启用某功能 | `QCheckBox` | 直接表达布尔状态 |
| 少量互斥选项 | `QRadioButton` + `QButtonGroup` | 选项一直可见，适合二选一或三选一 |
| 多行普通文本 | `QPlainTextEdit` | 适合说明、日志、纯文本 |
| 富文本编辑/显示 | `QTextEdit` | 支持格式化文本、HTML 子集 |
| 只读短文字或图片 | `QLabel` | 展示信息，不是文本输入控件 |
| 日期 | `QDateEdit` | 直接处理日期，减少字符串解析 |
| 操作 | `QPushButton` | 明确让用户触发一次动作 |

不要把所有输入都做成 `QLineEdit`，然后在各处写字符串转换。年龄用整数控件，可以减少一大类非法输入；日期用日期控件，也不必自己纠结“2026/9/2”和“2026-09-02”的差别。

## 5.2 QLineEdit：显示内容不等于读取内容

下面是完整示例中的局部片段，不能独立运行：

```python
self.name_edit = QLineEdit()
self.name_edit.setPlaceholderText("填写你的昵称")
self.name_edit.setMaxLength(30)

self.password_edit = QLineEdit()
self.password_edit.setEchoMode(QLineEdit.EchoMode.Password)
```

`setPlaceholderText()` 提供没有输入时的提示，不会填入真实内容。读取值使用 `text()`，得到 Python `str`。输入框只有占位文字时，`text()` 仍是空字符串。

`setMaxLength(30)` 限制最大长度。`setEchoMode(...Password)` 让输入看起来像密码，不会把内存中的明文自动加密；`text()` 仍返回原文。所以示例只做练习校验，不把密码输出、记录或保存。真实认证系统还涉及完全不同的密码存储和服务端流程。

| 常用 API | 参数/返回 | 什么时候用 |
| --- | --- | --- |
| `setText(text)` | `str → None` | 用已有数据填入输入框 |
| `text()` | `str` | 提交时读取当前内容 |
| `clear()` | `None` | 清空内容 |
| `setReadOnly(True)` | `bool → None` | 允许查看和复制，但不允许修改 |
| `setPlaceholderText(text)` | `str → None` | 给输入方式提示，不能取代字段标签 |
| `textChanged(text)` | 信号参数 `str` | 用户编辑或程序改文本后更新相关显示 |
| `textEdited(text)` | 信号参数 `str` | 主要关注用户编辑，`setText()` 不触发它 |
| `returnPressed()` | 无参信号 | 用户按回车时触发；校验器可能影响是否发出 |
| `editingFinished()` | 无参信号 | 编辑完成，如按回车或满足条件的焦点离开 |

普通名称常使用 `.text().strip()` 去掉两侧空白。密码是否允许前后空白取决于明确规则，不能为了“统一处理”随意 `.strip()` 改掉用户实际输入。

Qt 提供 `QIntValidator`、`QDoubleValidator`、`QRegularExpressionValidator`，可通过 `setValidator()` 限制可接受文本。它们在 QtGui 中，返回的校验状态区分 Invalid、Intermediate、Acceptable。例如输入 `-` 可能是暂时未完成的中间状态。输入过程中的限制不能替代提交时的完整业务校验。

## 5.3 数字输入：值与显示格式分开

```python
self.age_spin = QSpinBox()
self.age_spin.setRange(13, 120)
self.age_spin.setValue(18)
self.age_spin.setSuffix(" 岁")
age = self.age_spin.value()
```

这里 `age` 是整数 `18`，不是字符串 `"18 岁"`。`setSuffix()` 只改变展示，不改变数据类型。`setRange(minimum, maximum)` 同时设置上下限；`setSingleStep(step)` 设置按箭头时的步长；`valueChanged(int)` 在数值实际改变时发出。

小数使用 `QDoubleSpinBox`，通过 `setDecimals(n)` 控制小数位数，`value()` 返回 `float`，变化信号是 `valueChanged(float)`。金额如果需要严格十进制精度，还要选择合适的业务表示，例如整数分或 `Decimal`；一个小数输入控件不能自动解决浮点精度问题。

不要对 `QSpinBox` 的 `text()` 手动去单位再转整数。既然控件已经提供 `value()`，就使用它。

## 5.4 选项的显示文字与稳定数据

示例使用下拉框表示学习基础：

```python
self.level_combo.addItem("刚开始学习", "beginner")
self.level_combo.addItem("可以写 Python 小脚本", "python")
self.level_combo.addItem("有其他 GUI 经验", "gui")

display_text = self.level_combo.currentText()
stable_code = self.level_combo.currentData()
```

`addItem(text, userData)` 的第一项给用户看，第二项是业务数据。`currentText()` 返回文字，`currentData()` 返回关联的数据，没有数据或没有当前项时可能为 `None`。显示文字将来可能改名或翻译，业务判断仍可使用稳定代码 `"python"`。

`currentIndex()` 返回当前项下标，第一项是 0，没有当前项时是 -1。`currentIndexChanged(int)` 在当前下标改变时触发，包括程序设置造成的改变；`activated(int)` 面向用户主动选择，即便选择同一项也可能触发。不要只按中文文字做存储键，也不要假设下标永远不会随着排序或选项增加而变化。

复选框的常见读值是 `isChecked() -> bool`，写值是 `setChecked(bool)`，变化信号是 `toggled(bool)`。三态复选框还有部分选中状态，此时应看 `checkState()` 与 `Qt.CheckState`，不要强行压成只有真假的含义。本书表单使用默认的二态。

## 5.5 多行文字、日期与互斥选项

`QPlainTextEdit` 读值使用 `toPlainText()`，写值使用 `setPlainText(str)`，追加一段使用 `appendPlainText(str)`。它的 `textChanged` 信号**没有文本参数**，需要在处理方法中自己读取。`QTextEdit` 则可以 `setHtml()` / `toHtml()`，但普通日志和备注不必引入富文本。

日期控件的 `date()` 返回 `QDate`，不是 Python 字符串。需要 Python 日期可用 `toPyDate()`；需要格式化显示可用 Qt 的格式字符串。下面是概念片段，需要先导入 `QDate` 和 `QDateEdit` 并放进已有窗口：

```python
date_edit = QDateEdit()
date_edit.setCalendarPopup(True)
date_edit.setDate(QDate.currentDate())
date_edit.setDisplayFormat("yyyy-MM-dd")
chosen_date = date_edit.date().toPyDate()
```

Qt 的日期格式字符串和 Python 的 `strftime("%Y-%m-%d")` 不是同一种语法。

少量互斥选项可用多个 `QRadioButton`。同一父控件下的单选按钮通常会自动互斥，但当一个界面里有多组选择时，应使用明确的 `QButtonGroup` 管理每组。QButtonGroup 管理逻辑分组，不是一个会画出边框的可见容器；可见分组容器叫 `QGroupBox`。

## 5.6 一次提交到底应该做什么

完整示例中的 `submit_form()` 按照清楚的流程工作：读取 → 检查 → 形成结果 → 展示。以下摘录仅说明局部规则：

```python
name = self.name_edit.text().strip()
password = self.password_edit.text()
if not name:
    self.result_label.setText("请先填写昵称。")
    self.name_edit.setFocus()
    return
if len(password) < 6:
    self.result_label.setText("练习密码至少需要 6 个字符。")
    self.password_edit.setFocus()
    return
```

提前 `return` 让错误输入无法进入后续成功逻辑。`setFocus()` 把用户带回需要修改的字段。错误文字具体指出如何改正，比只写“输入错误”有用。

示例还在 `update_submit_state()` 中根据“昵称非空且勾选说明”启用按钮。这是**交互提示**，真正的提交方法仍再次检查条件，因为将来可能通过其他入口调用它。按钮禁用状态不是业务规则的唯一保障。

这个小示例把检查放在窗口中以便理解；规则变多时，就采用第 1 章的纯函数方式，把校验和界面显示拆开。在程序中所有控件都创建完成后，再连接变化信号，可以避免初始化途中回调访问到尚不存在的控件。

## 5.7 重置也是一个完整状态变化

`reset_form()` 不仅清空昵称，还恢复年龄、选项、复选框、结果文字和键盘焦点。修改输入框会发出 `textChanged`，修改复选框会发出 `toggled`，所以按钮状态会重新计算。

初学者容易只清空显示，忘记真实数据或相关按钮状态。每写一个重置操作，都列出“哪些值是默认值，哪些信息要清除，光标应该回到哪里”。程序以后有数据模型时，重置还要同步模型与界面。

## 5.8 本章练习与自检

1. 给表单新增一个 `QSpinBox`，表示每天学习分钟数，范围 10～240、步长 10，提交后显示数值。
2. 把昵称规则改成去空格后 2～20 个字符，分别验证空白、1 个字、20 个字和 21 个字。不要只依赖 `setMaxLength()`。
3. 增加“首选练习方向”的下拉框，分别保存中文显示与稳定代码，并打印代码以验证。
4. 给重置补充一个日期字段，要求恢复到今天；说明读取后得到的是哪一种日期对象。
5. 独立做一个“学习计划表单”：课程名、每日分钟数、学习天数、是否提醒。提交时展示总分钟数；先写输入规则与结果格式，再写界面。
