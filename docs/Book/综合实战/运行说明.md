# 综合实战运行说明

这是第 22 章的完整教学项目。依赖为 Python 3.12+ 与 PyQt6，数据层测试只用 Python 标准库。全部文件保存在同一目录；中文模块名是合法 Python 标识符。行业项目也常用英文模块名，本例为了中文教材使用中文文件名。

从 EasyFrp 项目根目录运行：

```powershell
python "docs/Book/综合实战/启动程序.py"
python "docs/Book/综合实战/测试任务仓库.py"
python "docs/Book/综合实战/测试任务窗口.py"
```

如果使用第 03 章创建的学习虚拟环境，将 `python` 替换为 `.\docs\Book\.venv\Scripts\python.exe`。直接运行入口文件时，Python 会把该文件所在目录放入模块搜索路径，因此同目录的中文模块能够导入。不必修改系统的 `PYTHONPATH`。

文件职责：

| 文件 | 作用 |
|---|---|
| [任务数据.py](任务数据.py) | 不可变任务对象、字段规则、创建与完成状态切换 |
| [任务仓库.py](任务仓库.py) | JSON 读取、结构校验、临时文件保存后替换 |
| [任务窗口.py](任务窗口.py) | 控件、用户操作、文档状态、错误提示 |
| [启动程序.py](启动程序.py) | 创建应用和窗口，进入事件循环 |
| [测试任务仓库.py](测试任务仓库.py) | 正常读写、坏输入与保存失败等自动测试 |
| [测试任务窗口.py](测试任务窗口.py) | 添加、筛选后操作、保存取消、坏文件和关闭保护等交互测试 |

程序启动时得到一份空白文档。通过“文件 → 保存”选择自己的练习 JSON 文件；下次通过“文件 → 打开”读取。它不自动读取 EasyFrp 配置，不自动在启动目录保存文件。

界面测试会快速创建并关闭测试窗口，用临时目录保存数据，并用预设回答代替文件和消息对话框。自动化环境可以在运行测试前设置 `$env:QT_QPA_PLATFORM = 'offscreen'`；测试后用 `Remove-Item Env:QT_QPA_PLATFORM` 恢复当前终端。离屏验证不代替在真实桌面上检查布局、输入法和显示缩放。

可操作功能：添加任务、选择优先级、搜索名称、切换完成状态、删除确认、新建、打开、保存、另存为、未保存退出确认。标题前的 `*` 表示内存内容尚未成功保存。搜索只改变展示，不改变文件内容。
