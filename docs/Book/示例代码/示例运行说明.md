# 示例运行说明

这些脚本与 EasyFrp 主程序相互独立。先按第 03 章安装学习环境，再从项目根目录运行其中一个文件。下列命令使用独立学习解释器；已有正确环境时可把前半段替换为对应的 `python`。

```powershell
.\docs\Book\.venv\Scripts\python.exe "docs/Book/示例代码/第一课_你好窗口.py"
```

| 文件 | 建议读完的章节 | 可以观察或尝试什么 |
|---|---|---|
| [第一课_你好窗口.py](第一课_你好窗口.py) | 03、04 | 控件、窗口、点击计数、事件循环 |
| [第二课_注册表单.py](第二课_注册表单.py) | 05、06 | 输入、密码遮挡、校验、布局与重置；仅演示表单，不创建真实账户 |
| [第三课_信号练习.py](第三课_信号练习.py) | 07 | 数字框、滑块和数据对象同步，信号屏蔽与边界 |
| [第四课_多页面窗口.py](第四课_多页面窗口.py) | 08～10 | 菜单、动作、页面、输入对话框及非模态窗口 |
| [第五课_模型表格.py](第五课_模型表格.py) | 11、12 | 排序、编辑、勾选、多行删除和委托；数据只保存在内存 |
| [第六课_设置与文件.py](第六课_设置与文件.py) | 13 | UTF-8 文本文件读写、未保存提示、设置保存；仅操作练习文件 |
| [第七课_后台任务.py](第七课_后台任务.py) | 15 | 进度、协作取消、模拟失败、运行中关闭 |
| [第八课_进程日志.py](第八课_进程日志.py) | 16 | 启动本机 Python 演示子进程，中文日志、停止、退出码 |
| [第九课_网络请求.py](第九课_网络请求.py) | 17 | HTTP/HTTPS 请求、取消、超时、响应上限；默认地址 example.com |

第六课使用 `QSettings` 保存窗口偏好。其实际位置取决于平台和脚本设置的应用身份，Windows 默认通常是当前用户注册表；它不是往 EasyFrp 配置写数据。第九课只有按下“请求”才发起请求；网络不可用时，观察错误处理也属于本课学习内容。高级示例的进一步前提和限制见对应章节。

脚本是为了突出单个知识点而做的小程序，未必包含综合项目的全部保护措施。例如第五课没有持久化、撤销和删除确认；第八课以 Python 解释器启动演示代码，不适合原样冻结后仍把 `sys.executable` 当 Python。把它们用于自己的项目时，先补齐相应需求。

与 GUI 无关的教材结构检查可以运行：

```powershell
python "docs/Book/示例代码/教材自检.py"
```

它检查教材 Python 文件语法和本地 Markdown 链接，不会自动点击窗口、联网、创建学习环境或修改练习数据。综合项目及其自动测试另见[运行说明](../综合实战/运行说明.md)。
