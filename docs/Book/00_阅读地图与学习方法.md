# PyQt6：从第一个窗口到独立开发

这本书写给这样的你：会变量、条件、循环、列表、函数等 Python 基础，知道 PyQt 是桌面界面框架，接触过一点 MFC，但还没有完整开发过一个桌面项目。你不必先把 Python 所有高级语法学完。用到的类、继承、异常、模块等知识，会在第 01 章补齐。

**最终目标是：给你一份小型桌面工具的需求，你能拆分功能、查文档、写出程序、定位错误、验证结果、交付给另一台电脑的使用者。** 独立开发并不意味着背下全部 API，也不意味着永远不查资料。它意味着你能判断方案是否正确，知道遇到问题后下一步查哪里，并能解释自己写的每一段关键代码。

## 本书如何使用

正文采用 Markdown，代码可直接在编辑器里查看。请先阅读章节，再打开链接的示例；不要一次启动全部程序。文中区分“完整示例”和“片段”：完整示例有导入、窗口、入口；片段是对局部逻辑的说明，需要放回对应类或函数。

本书以 **Python 3.12+、PyQt6、Qt Widgets** 为主线，在 Windows PowerShell 下给出操作命令。本次编写使用的验证环境详见[验证记录](27_示例验证记录.md)。Qt Quick、音视频、数据库、网络等会说明用途和进一步学习入口；不同平台和安装包的模块、插件可能不同，以你的环境和官方文档为准。

这是一条从概念到工程能力的学习路线，不是逐项翻译 Qt 的全部类和函数。Qt 的 API 数量很大，完整掌握的方法是先理解对象、事件、信号、布局与数据模型，再学会沿文档查具体方法。常用方法集中在[第 24 章](24_常用API与术语速查.md)，模块选择见[第 21 章](21_扩展模块与技术选择.md)。

## 每章固定采用的学习动作

1. **先预测。** 不运行代码，写下窗口会有什么、点击后哪一个函数执行、谁保存数据。
2. **再观察。** 运行完整示例，对照输出。预测错了就在旁边写出实际原因。
3. **做一个变化。** 改一个默认值、增加一种输入、换一种控件。一次只改变一个问题。
4. **合上代码复写。** 可以查官方方法说明，但不要逐行照抄原例。
5. **制造一次失败。** 空输入、取消文件选择、文件损坏、重复点击、任务中关窗，都要主动试。
6. **讲给别人听。** 用自己的话解释“数据在哪里、谁发信号、谁接收、什么时候保存”。解释不清的部分就是下一次复习点。

保留一个自己的“开发笔记.md”，每条只记问题、复现步骤、原因、修复和防止复发的方法。这样的笔记比复制大量代码更能提升独立排错能力。

## 怎样逐步减少对 AI 的依赖

前 07 章允许对照完整例子，但要求你能改写；08～14 章先自己画控件树和数据流，再看参考；15～21 章先查官方文档并做最小实验；22 章先按需求做一个版本，再对照实现；23 章的毕业任务只保留需求和验收清单，不提供整套答案。

遇到卡点，按顺序尝试：读报错最后几行 → 找自己代码中的对应行 → 输出关键变量 → 缩成最小复现 → 查该类文档 → 查版本差异。至少记录一次自己的判断和验证结果，再寻求帮助。目标不是硬扛，而是每次帮助都能转化成下次自己解决的能力。
